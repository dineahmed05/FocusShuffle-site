# موقع FocusShuffle (صفحة هبوط + تحميل مباشر)

موقع ثابت (HTML/CSS/JS فقط) جاهز للنشر **مجاناً** على GitHub Pages. لا يحتاج بناء ولا Node ولا أي أداة.

## ماذا يوجد في المجلد؟ (كل الملفات في مستوى واحد، بلا مجلدات، ليسهل رفعها من الهاتف)

| الملف | وظيفته |
|---|---|
| `index.html` | الصفحة الرئيسية بكل الأقسام |
| `style.css` | التصميم |
| `app.js` | تجربة الخلط، التبويبات، نافذة ملاحظة التحميل |
| `FocusShuffle-v0.6.1.apk` | ملف التطبيق الذي يُحمَّل مباشرة |
| `img-*.webp` (40 صورة) | لقطات الشاشة المقصوصة |
| `favicon.svg`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` | الأيقونات |
| `og-image.png` | صورة المعاينة عند مشاركة الرابط |
| `404.html` | صفحة الخطأ |
| `robots.txt` | لمحركات البحث |
| `.nojekyll` | يمنع GitHub من معالجة الملفات بـ Jekyll (ملف فارغ، قد يكون مخفياً في هاتفك) |

## النشر من الهاتف (بدون حاسوب)

1. حمّل ملف `FocusShuffle-site.zip` وفك ضغطه بتطبيق «الملفات» (اضغط على الملف ثم «استخراج»).
2. افتح github.com وسجّل الدخول. اضغط **+** ثم **New repository**.
3. اكتب اسم المستودع، مثلاً `focusshuffle`. اختر **Public** (ضروري للنشر المجاني). اضغط **Create repository**.
4. في صفحة المستودع الفارغة اضغط رابط **uploading an existing file**.
5. اضغط **choose your files** ثم حدد **كل الملفات** داخل المجلد المفكوك (في منتقي الملفات: القائمة ⋮ ← «تحديد الكل»). انتظر حتى ينتهي رفعها كلها (حوالي 52 ملفاً).
   - الحد الأقصى في الرفعة الواحدة 100 ملف. إن ظهر خطأ فارفع على دفعتين.
   - إن لم يظهر `.nojekyll` في المنتقي فلا مشكلة، الموقع يعمل بدونه. أو أنشئه بـ **Add file ← Create new file** باسم `.nojekyll` وأبقه فارغاً.
6. اضغط **Commit changes**.
7. ادخل **Settings ← Pages**. تحت **Build and deployment** اختر Source: **Deploy from a branch**، وBranch: **main** والمجلد **/ (root)**، ثم **Save**.
8. انتظر 1 إلى 3 دقائق، ثم حدّث الصفحة. سيظهر الرابط في أعلى صفحة Pages:
   `https://اسم-حسابك.github.io/اسم-المستودع/`
9. افتح الرابط وجرّب زر التحميل وتأكد أن ملف الـ APK ينزل.

> إن ظهرت صفحة 404 في أول دقيقتين فانتظر قليلاً. إن بقيت: تأكد أن `index.html` في **جذر** المستودع وليس داخل مجلد، وأن الاسم بحروف صغيرة تماماً.

## النشر من حاسوب (Git)

```bash
git init
git add .
git commit -m "FocusShuffle site"
git branch -M main
git remote add origin https://github.com/USERNAME/focusshuffle.git
git push -u origin main
```
ثم نفّذ الخطوة 7 أعلاه (Settings ← Pages).

## تحديث التطبيق لاحقاً (إصدار جديد)

1. ارفع الـ APK الجديد إلى المستودع (Add file ← Upload files). يُفضّل تسميته `FocusShuffle-v0.6.2.apk` مثلاً.
2. عدّل `index.html` (زر القلم في GitHub) وابحث عن `FocusShuffle-v0.6.1.apk` واستبدله بالاسم الجديد في **ثلاثة أماكن** (زران ونافذة إعادة التحميل)، وعدّل رقم الإصدار والحجم.
3. غيّر بصمة SHA-256: على الحاسوب `sha256sum FocusShuffle-v0.6.2.apk`، وعلى الهاتف استعمل أي تطبيق يحسب SHA-256. ضعها مكان القديمة في `index.html` (ابحث عن `shaText`).
4. احذف الـ APK القديم إن أردت توفير المساحة.
5. احفظ (Commit). يتحدث الموقع خلال دقيقة أو اثنتين.

## تغيير أشياء بسيطة

- **رابط تلجرام**: ابحث عن `dineahmed055` في `index.html` وغيّره.
- **إنستغرام**: ابحث عن `dineahmed05`.
- **الألوان**: أول سطور `style.css` (المتغيرات `--blue` و`--ink`...).
- **اسم الموقع في المتصفح**: وسم `<title>` أعلى `index.html`.

## نطاق خاص (اختياري)

Settings ← Pages ← Custom domain، ثم أضف سجل CNAME عند مزوّد النطاق يشير إلى `USERNAME.github.io`.

## حدود مهمة في GitHub Pages المجاني

- المستودع Public والموقع عام.
- حجم الموقع الموصى به أقل من 1 غيغابايت، والنطاق الترددي الموصى به 100 غيغابايت شهرياً. ملف الـ APK هنا 1.3 ميغابايت فقط، فهذا يكفي لعشرات الآلاف من التحميلات.
- الخط العربي (IBM Plex Sans Arabic) يُحمَّل من Google Fonts. إن تعطل فيستعمل الموقع خطاً احتياطياً من النظام دون مشكلة.

## ملاحظة عن تحذير Play Protect

النافذة التي تظهر بعد زر التحميل تشرح للمستخدم: «عرض المزيد» ← «تثبيت على أي حال». نصها في `index.html` داخل `id="dlModal"`. تختلف أسماء الأزرار قليلاً بين الهواتف، لذلك كُتبت بصيغة عامة.
